\small\color{muted}\centering
An external ML review flagged the soft/general\_shelf\_life specialist's test
$R^2=0.971$ as symptomatic of overfitting. This report tests that claim
directly: 15 model families across five complexity classes, K-fold
cross-validation at $K{=}5$ and $K{=}10$, and a trial with the validation
split removed --- all trained on the same context-grouped 70/15/15 split
($n_{\text{train}}{=}6{,}160$, $n_{\text{val}}{=}1{,}320$,
$n_{\text{test}}{=}1{,}320$) as production, so every result below is
directly comparable.
\end{minipage}

% ============================================================
\section{Model Complexity Classes}
% ============================================================
Five classes, ordered from highest to lowest capacity. Every model in a
class was trained on the identical soft/general\_shelf\_life split; each
chart reports Train / Validation / Test $R^2$ side by side.

% ---------------- Class 1 ----------------
\subsection{Class 1 --- High-Capacity Production Ensembles}
The four models currently in production: unlimited-depth Random Forest
(400 trees), early-stopped LightGBM and XGBoost (2{,}000 rounds), and an
Explainable Boosting Machine (3{,}000 rounds, 10 interactions). This is the
class the reviewers' concern was aimed at.

\section{Where the Real Problem Is}
% ============================================================
Every model class above was re-run on \texttt{hard/safety\_endpoint}. All 14
regressors score \textbf{negative test $R^2$} --- including on their own
training data for several. This is underfitting, not overfitting: 93--100\%
of this segment's labels are right-censored lower bounds ("still intact,
never failed"), not observed failure times.

% ============================================================
\section{Conclusion}
% ============================================================
\begin{itemize}[leftmargin=1.2em,itemsep=0.2em]
  \item \textbf{Not overfitting.} Simplifying capacity by orders of
  magnitude (2{,}000-round LightGBM $\rightarrow$ a 15-leaf tree
  $\rightarrow$ a straight line) costs at most 0.06 $R^2$ on
  soft/general\_shelf\_life. $K$-fold CV reproduces the fixed holdout within
  $\pm0.005$. Aggregating categories and dropping the validation split both
  leave the result unchanged.
  \item \textbf{Root cause.} All V7 training rows are synthetic, generated
  from 18--20 rules per category (verified: \texttt{data\_origin} is 100\%
  synthetic). Any model family learns $\sim$20 rules well; that is not
  memorized noise, it is a correctly-fit low-dimensional generator. The real
  ceiling is sim-to-real generalization, already measured separately
  (external literature test, \texttt{docs/GENERALIZATION\_ANALYSIS.md}).
  \item \textbf{Genuine finding.} \texttt{hard/safety\_endpoint} underfits
  on all 14 model families --- a censored-regression formulation is needed,
  not a smaller model.
\end{itemize}
