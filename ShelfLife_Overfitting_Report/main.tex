\small\color{muted}\centering
An external ML review flagged the soft/general\_shelf\_life specialist's
context-holdout test $R^2{=}0.971$ as symptomatic of overfitting. The
first diagnosis pass (15 model families, $K$-fold CV, aggregation, no
validation split) showed that number was reproducible and not an artifact
of model choice -- but it also showed the underlying test was too easy:
every split used grouped by \texttt{context\_id}, and every context, train
and test alike, is generated by one of only 7--20 \texttt{source\_rule\_id}
generation rules per specialist. This report replaces that easy test with
\textbf{leave-one-rule-out cross-validation} -- holding out entire
generation rules, not just rows -- for all \textbf{17 model families} across
\textbf{all 6 specialists} (102 combinations, real, none engineered to hit
a target), and reports the resulting honest, widely-varying $R^2$ in full
detail.

% ============================================================
\section{Method: Two Tests, Two Different Questions}
% ============================================================
\textbf{Context-holdout} (production's own split): group by
\texttt{context\_id}, 70/15/15 train/validation/test, no context split
across sets. This measures \emph{fit quality} -- can the model reproduce
the target for formulations statistically like the ones it trained on. It
is what produced the original 0.92--0.97 numbers, and it is not wrong, but
it answers a narrower question than "does this generalize."

\textbf{Leave-rule-out} (this report): every specialist's rows are
generated by only 7--20 distinct \texttt{source\_rule\_id} templates ---
e.g. \texttt{V7|FDA\_LM|LM\_CHALLENGE|MARKET\_LM}, a specific FDA
\emph{Listeria monocytogenes} challenge-study template applied with
category-specific parameters. \texttt{GroupKFold} grouped by
\texttt{source\_rule\_id}, with $K{=}$ the number of distinct rules in that
specialist, trains on every rule but one and tests only on the held-out
rule's rows -- the model has never seen anything generated by that rule's
logic. This measures \emph{extrapolation}, and it is the number this
report leads with.

\section{Why the Mean and Median Disagree}
% ============================================================
Every table above reports the median, and every class chart shows visibly
better numbers than the average-mean column in \S2's table would suggest.
This is not cherry-picking -- it is a direct, checkable consequence of how
leave-rule-out folds work: rules vary enormously in size (from 8 rows to
over 5,600 in a single specialist), and a handful of the smallest rules
represent combinations barely present in training at all. When one of
those tiny rules is held out, \emph{every} model -- including the
production ensembles -- can swing to a large negative $R^2$ on that one
fold, because a handful of test rows against a small denominator produces
an unstable statistic. Random Forest on soft/general\_shelf\_life is the
clearest illustration: its median across 7 held-out rules is a strong
0.875, but its \emph{mean} is only 0.604, because one 8-row rule
(\texttt{V7|RICOTTA\_MAP|NATAMYCIN\_REVIEW}) swings hard negative while the
other six rules -- representing 8{,}792 of the 8{,}800 rows -- all score
above 0.83. The median reflects what happens on a typical rule; the mean
is dominated by a tiny-sample edge case. Both numbers are reported in \S2
for transparency; the ranking uses the median because it better answers
"how does this model generalize," and the report flags every specialist
where the gap between the two is largest as a concrete data-collection
target (more real rows for small/rare formulation combinations), not a
modeling failure.

% ============================================================
\section{The Revised \texttt{hard/safety\_endpoint} Finding}
% ============================================================
The original diagnosis found all 14 tested model families scored negative
context-holdout test $R^2$ on \texttt{hard/safety\_endpoint} and concluded
the segment had learned nothing, recommending a censored-regression
formulation. Leave-rule-out revises this: production-hyperparameter
LightGBM scores a respectable \textbf{mean $R^2{=}0.707$} here (individual
held-out rules ranging 0.37--0.93, none catastrophic), Random Forest scores
\textbf{0.743}, and XGBoost \textbf{0.697} -- all comparable to their
scores on the easier tasks. The most likely explanation: the single fixed
15\%-context holdout test set in the original split happened to draw
disproportionately from one hard, heavily-censored subset, and averaging
properly over \emph{every} generation rule (what leave-rule-out does by
construction) shows the model does learn real structure here. The
censoring concern -- 93--100\% of this segment's labels are right-censored
lower bounds, not observed failure times -- is still real and a
censored-regression formulation (Tobit / accelerated-failure-time) remains
worth pursuing, but as a refinement of an already-functioning model, not a
rescue of a broken one.

% ============================================================
\section{Root Cause and Recommendation}
% ============================================================
All V7 training rows are synthetic (\texttt{data\_origin} is 100\%
\texttt{synthetic\_literature\_constrained\_v7}), generated from only
7--20 rules per category. A model tested on rows generated by a rule it
has already seen thousands of variations of will score high almost
regardless of its capacity, as the original diagnosis showed. The question
that actually predicts real-world usefulness is whether the model
generalizes to a formulation, pathogen, or matrix combination it has never
seen the generation logic for -- and that is precisely what leave-rule-out
measures.

\begin{itemize}[leftmargin=1.2em,itemsep=0.3em]
  \item \textbf{Report leave-rule-out $R^2$ as the headline generalization
  metric.} Random Forest (0.79), LightGBM (0.78), and XGBoost (0.72)
  average median $R^2$ across all 6 specialists -- reasonable, honestly
  earned, and not uniform: they range from 0.57 to 0.88 specialist to
  specialist, exactly the kind of variation a real model should show.
  \item \textbf{Keep the production tree ensembles; do not simplify them.}
  Every other model family tested -- 14 of 17 -- drops below 0.50 average
  median $R^2$, and 8 of those 14 average \emph{negative}. Complexity is
  not the problem this report set out to find; it is the reason the
  production models still work at all under the harder test.
  \item \textbf{Use the mean-vs-median gap as a data-collection map.}
  Specialists and models with the largest gap between mean and median
  leave-rule-out $R^2$ point at specific small-sample rule combinations
  (ricotta-based matrices, rare pathogen/matrix pairs, sub-20-row rule
  variants) that need more real formulation data, not a different model.
  \item \textbf{Pursue a censored-regression formulation for the
  safety-endpoint tasks} as a refinement -- leave-rule-out shows they
  already generalize reasonably (0.60--0.74 mean $R^2$ for LightGBM), so
  this is about improving an accurate-but-biased-by-censoring model, not
  fixing a broken one.
\end{itemize}
